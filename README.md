# 한 바퀴 여행

폰 가로 화면에서 2~4명이 즐기는 한국 도시 여행 보드게임. 땅을 사고, 건물을 짓고, 통행료를 모아 1등이 된다.
주사위는 **폰을 흔들어서** 굴린다. 사람이 모자라면 컴퓨터(AI)가 빈자리를 채운다.

## 하는 방법

- **한 폰으로 하기:** 컴퓨터와 함께 (사람 자리가 여러 개면 폰을 돌려가며).
- **방 만들기 / 방 들어가기:** 각자 자기 폰으로. 방장이 만든 4자리 코드를 친구가 입력하면 된다.
- 주사위는 폰을 흔들거나 "주사위 굴리기" 버튼으로 굴린다. (아이폰은 시작할 때 움직임 센서 허용을 눌러야 한다.)
- 칸을 누르면 땅값과 통행료 설명이 나온다.
- 배포된 주소에서 브라우저 메뉴의 "홈 화면에 추가"를 누르면 주소창 없이 전체 화면으로 열린다.

## 개발

```
npm install
npm run dev -- --host    # 개발 서버 (같은 와이파이의 폰에서 http://컴퓨터IP:5191/ 로 접속)
npm test                 # 규칙·AI·온라인 프로토콜 테스트
npm run build            # 배포용 빌드 (dist)
```

개발용 주소 옵션: `?dev=online` 방장+참가자를 한 화면에서 시험(가짜 서버), `?pid=이름` 같은 컴퓨터의 탭 두 개를 서로 다른 기기처럼 시험.

## 구조

기획은 `docs/01-design.md`, 온라인 설정은 `docs/02-online-setup.md`. 수치와 내용은 모두 `data/*.json`에 있다.

```
data/         판(32칸), 여행카드, 규칙 수치 (JSON)
src/engine/   게임 규칙 (화면 없는 순수 로직 + 테스트)
src/ai/       컴퓨터 플레이어
src/net/      온라인: 방 만들기·입장·상태 주고받기 (Firebase 실시간 DB, 시험용 가짜 DB)
src/ui/       화면, 애니메이션, 소리, 흔들기 감지
```
