# 온라인 대전 설정 (Firebase)

게임 파일은 GitHub Pages가 내려주고, 폰끼리 실시간으로 주고받는 일은 Firebase 실시간 데이터베이스가 맡는다.
무료 요금제(Spark)로 충분하다 (동시 접속 100명, 한 달 10GB 전송).

## 1. 프로젝트 만들기

1. https://console.firebase.google.com 에 구글 계정으로 로그인
2. **프로젝트 추가** → 이름 예: `hanbakwi-trip` → 애널리틱스는 **사용 안 함** → 만들기

## 2. 실시간 데이터베이스 만들기 (웹 앱 등록보다 먼저)

1. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치: **싱가포르 (asia-southeast1)** (한국과 가장 가까움)
3. **테스트 모드로 시작** → 사용 설정
4. 위쪽에 보이는 주소 `https://…firebasedatabase.app` 을 적어 둔다

## 3. 규칙 넣기 (테스트 모드는 30일 뒤 막히므로 꼭 교체)

**규칙** 탭의 내용을 아래로 바꾸고 **게시**:

```json
{
  "rules": {
    "rooms": {
      "$code": {
        ".read": "$code.matches(/^[0-9]{4}$/)",
        ".write": "$code.matches(/^[0-9]{4}$/)"
      }
    }
  }
}
```

- 방 코드(숫자 4자리)를 아는 사람만 그 방을 읽고 쓸 수 있고, 방 목록은 볼 수 없다.
- 친구끼리 하는 게임이라 로그인은 두지 않았다. (방 코드를 남에게 알려 주지 않으면 된다.)

## 4. 웹 앱 등록하고 설정값 얻기

1. 프로젝트 홈에서 **웹 아이콘 `</>`** → 앱 닉네임 `web` → (Hosting 체크 안 함) → **앱 등록**
2. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값을 모두 복사한다.
   `databaseURL`이 없으면 2번의 데이터베이스 주소를 넣는다.
3. `src/net/firebaseConfig.ts`의 `FIREBASE_CONFIG`에 붙여 넣는다. (이 값은 웹페이지에 그대로 들어가는 공개용 식별값이라 저장소에 올려도 된다.)

## 진행 구조

```
rooms/{4자리 코드}/
  meta      방장 기기, 상태(lobby/playing/over), 바퀴 수, 참가자 목록(roster)
  slots/0~3 자리별 { kind: empty|human|ai, name, pid }
  state     방장이 올리는 게임 상태 { seq, json }
  actions/  참가자가 보내는 행동 (방장이 받아서 처리하고 지운다)
```

- **방장 폰이 규칙 담당**이다. 참가자는 자기 차례에 행동만 보내고, 방장이 규칙대로 처리한 새 상태를 모두가 받아 본다.
- 컴퓨터(AI) 자리도 방장 폰이 움직인다. 그래서 **방장이 앱을 닫으면 게임이 멈춘다** (다시 열면 이어서 진행).
- 참가자가 오래 응답이 없으면 방장 화면에 "컴퓨터가 대신 하기" 버튼이 나온다.
- 폰에서 다른 앱을 쓰다 돌아와 페이지가 새로고침돼도, 같은 폰(기기 식별값)이면 방과 자리로 돌아온다.
