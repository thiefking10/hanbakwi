# 한 바퀴 여행 (가칭) — 기획

폰 가로 화면에서 2~4명이 즐기는 한국 도시 여행 보드게임. 주사위는 폰을 흔들어서 굴린다.
(부루마블/모노폴리 같은 "땅 사기" 규칙이지만, 이름·판·그림은 우리만의 것으로 만든다.)

## 1. 목표

- 2~4명. 사람이 모자라면 AI가 빈자리를 채운다 (사람 1명 + AI 3명도 가능).
- 각자 자기 폰으로 참여한다 (온라인). 혼자서 AI와만 하는 연습 판도 된다.
- 폰을 흔들어 주사위를 굴린다. 흔들림 센서가 없거나 거절하면 "굴리기" 버튼을 쓴다.
- GitHub Pages로 배포한다 (서버 없이 정적 파일만).

## 2. 규칙 (data/rules.json, board.json, cards.json에서 수치를 읽는다)

- 판은 32칸. 네 모서리: 출발 / 무인도 / 휴게소 / 세계여행.
- 칸 종류: 도시 19 (8개 색 묶음), 교통편 4, 여행카드 4, 세금 1.
- 시작 돈 1500만원, 출발점을 지나면 월급 80만원. 기본 40바퀴 제한(바퀴 수는 시작할 때 고른다).
- 주사위 2개. 더블이면 한 번 더. 더블 3연속이면 무인도.
- 빈 땅에 서면 살지 고른다. 남의 땅이면 통행료를 낸다.
- 같은 색 묶음을 모두 가지면 (건물이 없는 땅의) 통행료 2배.
- 내 도시에 서면 건물을 한 단계 올릴 수 있다 (땅 → 숙소 → 빌딩 → 랜드마크). 단계가 오를수록 통행료가 크게 오른다.
- 교통편은 가진 개수만큼 통행료가 오른다 (40 × 개수).
- 세금은 휴게소에 모이고, 휴게소에 서는 사람이 가져간다.
- 무인도: 더블이 나오면 탈출, 벌금 50만원을 내고 나올 수도 있고, 3번 실패하면 벌금을 내고 나온다.
- 세계여행: 원하는 칸으로 날아간다 (월급은 없음).
- 돈이 모자라면 싼 땅부터 반값에 자동으로 팔아서 낸다. 그래도 모자라면 파산 (땅은 은행으로).
- 한 명만 남으면 승리. 정해진 바퀴 수가 지나면 재산(돈 + 땅·건물 값)이 가장 많은 사람이 승리.

## 3. 구조

```
data/              모든 수치와 내용 (JSON)
src/engine/        게임 규칙. 화면 없이 동작하는 순수 로직 + 테스트
  types.ts           상태·행동·사건 형식
  board.ts           판 데이터, 통행료·땅값 계산
  game.ts            createGame, dispatch(상태, 행동) → 새 상태, legalActions
  rng.ts             저장 가능한 난수 (같은 시드면 같은 판)
src/ai/            (예정) AI가 legalActions 중 하나를 고른다
src/net/           (예정) 온라인 통신
src/ui/            (예정) 화면
```

- **규칙은 화면과 분리**한다. 상태는 JSON으로 저장·전송할 수 있는 단순한 값이고, 행동을 받아 새 상태를 돌려주는 방식(`dispatch`)이라 온라인 동기화가 쉽다.
- 게임 진행은 한 곳(방장)이 한다. 다른 사람은 "행동"만 보내고, 방장이 규칙대로 처리한 새 상태를 모두에게 보낸다. 방장 폰이 AI 차례도 대신 처리한다.

## 4. 온라인 방식 (GitHub Pages는 서버를 돌릴 수 없다)

GitHub Pages는 파일만 내려주는 곳이라, 폰끼리 연결해 주는 중간 장치가 따로 필요하다.

| 방법 | 설정 | 장점 | 단점 |
| --- | --- | --- | --- |
| A. 무료 실시간 데이터베이스 (Firebase 등) | 무료 프로젝트를 한 번 만들어야 함 | 안정적, 어떤 통신망에서도 됨, 새로고침 후 재접속 쉬움 | 계정과 설정이 필요 |
| B. 폰끼리 직접 연결 (WebRTC, PeerJS 등) | 없음 | 가입 불필요, 빠르게 시작 | 일부 통신망에서 연결 실패, 방장이 나가면 종료 |

- 통신 부분은 `src/net/`에 분리해서, 나중에 방식을 바꿔도 게임 규칙과 화면은 그대로 두도록 만든다.
- 방 만들기 → 4글자 방 코드 또는 링크 공유 → 친구가 코드를 입력해 입장 → 방장이 시작 (빈자리는 AI).

## 5. 주사위 흔들기

- `devicemotion` 이벤트로 가속도 크기를 재서, 짧은 시간에 일정 세기 이상 흔들리면 "굴리기".
- 아이폰은 사파리에서 첫 화면 터치 때 `DeviceMotionEvent.requestPermission()`을 한 번 요청해야 한다.
- 센서가 없거나 거절되면 버튼으로 굴린다. 컴퓨터 테스트용으로 스페이스도 지원한다.

## 6. 만드는 순서

1. 규칙 엔진 + 테스트 ✔
2. AI 플레이어 ✔ (성향 2가지: 과감/신중)
3. 화면: 판, 말 이동, 주사위, 땅 사기·건설 창, 안내문 (한 폰으로 사람+AI 판) ✔
4. 주사위 흔들기, 소리 ✔
5. 온라인 (방 만들기·코드 입장, AI 채우기): 방식은 Firebase 실시간 데이터베이스로 정함 → docs/02-online-setup.md. 코드는 구현했고 진짜 Firebase 연결은 설정값을 넣은 뒤 시험
6. 다듬기 (애니메이션, 밸런스) 후 GitHub Pages 배포 ✔ 배포 설정 완료
